# Зерно

Мобильное приложение кофейни: заказ навынос без очереди. React Native + Expo, один код для iPhone и Android.

## Что умеет версия 0.1

- выбор кофейни;
- меню с категориями и поиском;
- настройка напитка: размер, молоко, дополнительный шот, без сахара, количество;
- корзина: время готовности «как можно скорее» или ко времени;
- статус заказа с номером (пока без сервера: кофейня «готовит» заказ по таймеру);
- история заказов и повтор заказа;
- бонусная карта: каждый седьмой напиток в подарок.

Данные пока хранятся только в памяти и сбрасываются при перезапуске. Сервер, вход по телефону и оплата — следующий этап.

## Запуск на телефоне

1. Установите Node.js LTS с nodejs.org.
2. На телефон поставьте приложение **Expo Go** (App Store или Google Play).
3. Откройте папку проекта в терминале и выполните по очереди:

```
npm install
npx expo start
```

4. Отсканируйте QR-код из терминала: на iPhone камерой, на Android — в Expo Go. Телефон и компьютер должны быть в одной сети Wi-Fi.

Если установка оборвалась или пишет `Cannot find module`, удалите папку `node_modules` и файл `package-lock.json` и выполните `npm install` ещё раз. Антивирус может удалять файлы из `node_modules` во время установки: добавьте папку проекта в исключения.

## Структура

```
App.js                навигация, вкладки, уведомления
src/theme.js          цвета, шрифты, формат цены
src/data.js           кофейни, меню, расчёт цены позиции
src/store.js          корзина, заказы, бонусы
src/ui.js             кнопки, чипсы, степпер, переключатель, иконки
src/screens/          экраны: старт, меню, напиток, корзина, статус, заказы, профиль
```
